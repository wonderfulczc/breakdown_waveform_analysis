# breakdown_waveform_analysis
本项目用于 ML01 击穿放电波形数据的规范化处理、特征提取、波形分类、组统计与科研作图，目标是围绕“击穿放电产生的电磁信号与测量链排伪迹”建立可复查、可复现的数据处理流程。项目默认输入为按命名规则整理后的原始波形 CSV 文件，流程会完成波形格式识别、归一化导出、FFT 频域分析、独立峰识别、阻尼拟合、模板相关性计算、A-H 波形类别判定、组级统计、单波形/组图/对比图生成，并输出 CSV、Excel、日志和快速报告。当前版本固定参考组为 `G3_D0p3m_L1Mohm_Gcoax`；若该组不存在，则不生成兜底模板，
`fsrc`、`alpha_src`和模板相关系数保持空值，避免把不可信参考写入结果。仓库不包含原始数据和结果图表，`00_raw_csv/`与`04_results/` 已被排除；实验索引、配置、脚本、文档和 prompt 被保留用于复现实验流程。
